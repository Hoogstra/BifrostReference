## Legend
- 🔴 Red = Fire / Heat / Damage / Blood
- 🔵 Blue = Frost / Freezing / Water / Rooting
- 🟢 Green = Poison / Venom / Healing / Nature
- 🟡 Yellow = Lightning / Thunder / Holy / Fame
- 🟣 Purple = Confusion / Fear / Terror / Chaos
- ⚪ White = Neutral / Population / Resource / Colonization

## 🌍 Realms

| Realm | Conditions / Features |
|-------|------------------------|
| Midgard | ⚪ Standard first realm, limited buildings, no special conditions. |
| Niflheim (Frost) | 🔵 Map of islands, portals connect them. 🔵 Winters last 6 months. ⚪ Extra Town Halls can be repaired. |
| Muspelheim (Fire) | 🔴 No wood consumption. 🔴 Volcano center. 🔴 Rimsteel forging at Anvil of Gods. ⚪ No iron/stone deposits—must defeat golems. |
| Idavoll (Heat) | 🔴 Oppressive heat reduces production. 🟢 Oasis zones give bonuses. 🔴 Grafvitnir spawns; defeating them grants +10% attack (not persistent). |
| Nidavellir (Cave) | ⚪ Ore deposits block slots. ⚪ Miners extract crowns/stone. ⚪ Zones fade back into fog if unvisited. |
| Vanaheim (Jungle) | 🟢 Strong wild creatures reclaim zones. 🟢 Wolf dens/fox burrows cannot be colonized. 🟢 Hazardous, frequent attacks. |

## ⚔️ Blades (Weapon Powerups)

| Blade Type | Effect |
|------------|--------|
| Blood | 🔴 Units heal when dealing damage (life steal). |
| Confusion | 🟣 Units can turn enemies against allies briefly. |
| Fire | 🔴 Units burn enemies; trackers gain fire arrows. |
| Frost | 🔵 Units freeze enemies and slow attack speed. |
| Holy | 🟡 Units blind enemies (miss attacks for 3s). |
| Storm | 🔴 Units inflict area damage (AOE). |
| Terror | 🟣 Units cause fear (enemies flee). |
| Thunder | 🟡 Lightning strike chance (Mjölnir’s wrath). |
| Vanaheim | 🔵 Units root enemies (stun). |
| Venom | 🟢 Units poison enemies (DoT). |
